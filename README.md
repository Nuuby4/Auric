Auric does not have proxy support **yet**. The current version relies on Port Forwarding. To make a server joinable, you'll need to open port 25200 on your router and share your personal IP address (be cautious!).

### What's done:
* Server creation

* Networking
* Starting the game
* Player kicking/moderation
* Per-player team swapping
* Spectating Games (WIP)
* Load Levels Anytime
* Dynamic Map Rotation
* Unlock Everything
* Console Commands (Unlocking all + custom)

### What's planned:
* Player banning (WIP)
* Everything Proxies (database, server browser, etc)
* Persistence Manager
* Independent Game Launcher

**Stars and PRs are welcome!**
